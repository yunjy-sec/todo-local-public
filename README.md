# TodoPopup — 로컬 전용 빌드

완료·취소를 누를 때까지 **계속 다시 뜨는** 윈도우 할 일 팝업. 캘린더 창(일/주/월/연)과
트레이 상주를 포함합니다.

이 저장소는 **통신 기능을 소스에서 물리적으로 제거한** 빌드입니다. 기능 플래그로 꺼 둔 것이
아니라 파일과 코드가 존재하지 않습니다. 감사 절차는 [docs/AUDIT.md](docs/AUDIT.md) 를 보십시오.

```bash
cd app && npm run audit
```

## 실행

```bat
start-todo.bat
```

트레이 아이콘으로 상주합니다. **더블클릭** = 목록 창, **우클릭** = 메뉴(새 일정/목록/설정/종료).
캘린더 창은 `start-calendar.bat` 또는 트레이 메뉴에서 엽니다.

기본 단축키: `Ctrl+Alt+T` 목록 · `Ctrl+Alt+N` 새 일정 · `Ctrl+Alt+C` 캘린더.

## 일정 입력

자연어와 고전적 입력을 함께 씁니다. `내일 오후 3시 팀 회의`, `매주 화 10시 주간보고`,
`3일 뒤 14:30 치과` 처럼 적으면 해석해서 넣고, 날짜·시각·장소를 직접 고를 수도 있습니다.

시각 표기는 **24시간(`00:00`–`23:59`)이 기본**이고, 오전/오후 표기와 앞자리 0 없는 표기는
설정에서 켤 수 있습니다.

## 캘린더

캘린더는 **이 컴퓨터 안에만** 있습니다. 서비스 → 계정 → 캘린더 계층으로 여러 개를 만들고
색과 알람을 따로 지정합니다.

**ICS 파일 구독**(읽기 전용)을 지원합니다. 디스크의 `.ics` 파일 — 공유 폴더나 USB 로 받은
사내 일정표 — 을 등록하면 화면과 알람에 함께 나옵니다. 남의 캘린더라 편집은 막히지만,
**"내 화면에서 완료"** 표시는 남길 수 있습니다(원본은 건드리지 않고 이 컴퓨터에만 기록됩니다).

## 데이터 — 구글 캘린더 호환 스키마

`%APPDATA%\TodoPopup\todos.json` 은 구글 캘린더 API의 `events.list` 응답 형태입니다.
**구글에 접속하지 않습니다.** 스키마만 그 모양을 따릅니다 — 나중에 다른 도구로 옮기거나
표준 형식으로 내보낼 때 번역이 필요 없게 하려는 것입니다.

앱 전용 속성은 `extendedProperties.private` 에 넣습니다. 쓸 수 있는 키의 목록은
`app/shared/registry.js` 의 `PRIVATE_FIELDS` 하나뿐이고, 미등록 키는 검사가 막습니다.

## 검사

```bash
cd app
npm run check      # 문법
npm run lint       # 가드레일 11종
npm test           # 단위·회귀 129건
npm run check:ui   # 실제 창 25항목
npm run audit      # 감사 보고서
```

## 이 트리는 생성물입니다

기능 개발은 상류 저장소에서 이루어지고, 이 트리는 거기서 통신을 제거해 **재현 가능하게
생성**됩니다. 그래서 두 트리가 갈라지지 않습니다. 이 저장소에 직접 커밋한 수정은 다음
생성 때 사라집니다 — 고칠 것이 있으면 상류에 고쳐 주십시오.

## 실행 옵션

| 플래그 | 하는 일 |
|---|---|
| `--calendar` | 캘린더 창으로 바로 연다 (`start-calendar.bat` 이 이것을 쓴다) |
| `--hidden` | 창 없이 트레이로만 시작한다 (윈도우 시작 시 자동 실행에 쓴다) |
| `--test-popup` | 팝업을 한 번 띄워 위치·크기·투명도를 눈으로 확인한다 |
