# 감사 안내 — 로컬 전용 빌드

이 저장소는 **통신 기능을 소스에서 물리적으로 제거한** TodoPopup 빌드입니다.
기능 플래그로 꺼 둔 것이 아니라 파일과 코드가 트리에 존재하지 않습니다.

한 줄로 확인하십시오:

```bash
cd app && npm run audit
```

이 명령은 트리 전체를 훑어 통신의 흔적을 세고, **찾을 때 쓴 명령 자체를 함께 인쇄합니다.**
저희 스크립트를 믿지 않으셔도 됩니다 — 인쇄된 명령을 그대로 다시 치시면 같은 결과가 나옵니다.

## 무엇이 제거되었는가

| 제거된 것 | 원래 하던 일 |
|---|---|
| `app/main/sync/` | 원격 서버와 일정 동기화(HTTP) |
| `app/main/calendars/google*.js` | 구글 캘린더 연동(브라우저 인증 + REST) |
| `app/main/calendars/ics-fetch-url.js` | 원격 주소(https·webcal)에서 일정표 받아 오기 |
| `tools/sync-server.mjs` · `tools/web-server.mjs` | 동기화 서버 · 웹 버전 서버 |
| `web/` | 브라우저 화면 |
| 관련 설정·IPC 채널·저장소·시나리오 등록 | 위 기능을 가리키던 등록 항목 전부 |

제거는 등록표(`app/shared/registry.js`)와 계약(`app/shared/contracts.js`)까지 함께 이루어졌습니다.
이 저장소는 "등록된 것과 실제 코드가 어긋나면 검사가 실패하는" 구조라, 코드만 지우고 등록을
남겨 두면 `npm run lint` 가 빨개집니다. **검사가 초록이라는 사실 자체가 제거가 온전하다는 증거입니다.**

## 무엇이 남았는가 — 그리고 왜 통신이 아닌가

**디스크의 `.ics` 파일 읽기** (`app/main/calendars/ics-file.js`)
사내 공지 일정표를 USB나 공유 폴더로 받아 여는 길입니다. `fs` 로 파일을 읽을 뿐 소켓을 열지 않습니다.

**UNC 경로** (`\\파일서버\공유\팀일정.ics`)
`fs` 에게는 파일 경로입니다. SMB 프로토콜은 운영체제가 처리하며 이 코드는 관여하지 않습니다.
네트워크 파일 서버를 금지하는 정책이시라면 코드가 아니라 **OS·방화벽 수준에서** 막으셔야 합니다 —
이 앱은 그 둘을 구별할 수단이 없습니다.

**툼스톤(`deletedAt`)** — 원래 원격 동기화에 삭제를 전달하려고 만든 표식이지만, 지금은 이 앱의
**유일한 삭제 경로**입니다. 지우면 일정이 삭제되지 않습니다. 통신과는 무관합니다.

## 범위 밖 — 저희가 먼저 신고합니다

**`app/node_modules/` 의 Electron 런타임(Chromium).**
네트워크 스택이 바이너리에 링크되어 있어 코드로 제거할 수 없습니다. 이 빌드의 앱 코드는
그것을 호출하지 않지만, 바이너리 자체는 저희가 만든 것이 아니며 감사 범위에서 제외하기로
합의된 부분입니다. 실행 중 실제로 나가는 요청이 없음을 확인하시려면 아래 절차를 쓰십시오.

**의존성 설치.** `package-lock.json` 은 `registry.npmjs.org` 주소를 담고 있어 트리에서 제거했습니다.
런타임은 폐쇄망 반입 시 별도로 동봉합니다(`app/node_modules/`). 설치 행위 자체는 이 트리 밖입니다.

## 실행 중 관측 (권장)

정적 검사는 잠들어 있는 코드까지 잡지만 바이너리 안을 보지 못합니다. 반대로 실행 관측은
바이너리까지 보지만 실행되지 않은 경로를 놓칩니다. 둘을 함께 쓰십시오.

1. Windows 방화벽에서 `app/node_modules/electron/dist/electron.exe` 의 아웃바운드를 **차단**합니다.
2. 앱을 띄우고(`start-todo.bat`) 일정 추가·알림·캘린더 보기·`.ics` 열기를 모두 해 봅니다.
3. 기능이 그대로 동작하면, 이 앱은 나가는 통신에 의존하지 않는다는 뜻입니다.

`npm run check:ui` 는 실제 창을 띄워 25개 항목을 확인합니다. 이 스크립트는 창을 조종하려고
`127.0.0.1` 루프백으로 디버그 채널을 씁니다 — **외부로 나가는 통신이 아니며 개발 도구입니다.**
배포 산출물(`git archive`)에는 `app/scripts/check-ui.mjs` 와 `app/test/` 가 포함되지 않습니다
(`.gitattributes` 의 `export-ignore`). 검사 스크립트(`lint-*`·`audit`)는 **남깁니다** —
그것이 이 빌드의 증거이므로 감사관이 직접 돌리실 수 있어야 합니다.

## 검사 목록

```bash
cd app
npm run check      # 문법
npm run lint       # 가드레일 11종 (그중 lint:network 가 "네트워크 0" 을 검사)
npm test           # 단위·회귀 129건
npm run check:ui   # 실제 창 25항목
npm run audit      # 위를 묶어 감사 보고서 형태로 출력
```

`lint:network` 는 이 빌드에서 의미가 뒤집혀 있습니다. 원본 저장소에서는 "허용된 관문 밖에서
네트워크를 쓰지 않는가" 를 보지만, 여기서는 **관문이 하나도 없으므로** "트리 어디에도 없는가" 를 봅니다.
